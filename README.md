# Our Little Sanctuary

A single-file React app (no build step). PIN: 1432 (change `PIN` near the top of the script in index.html).

## Host on GitHub Pages
1. Create a new GitHub repository and upload `index.html` to the root.
2. Go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute your site will be live at https://YOUR-USERNAME.github.io/REPO-NAME/

Or just double-click index.html to open it locally (needs an internet connection for React and fonts).
